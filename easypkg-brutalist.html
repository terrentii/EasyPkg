:: Первый запуск

EasyPkg создаст группу easypkg и настроит sudo, чтобы участники группы могли устанавливать и удалять пакеты без ввода пароля.

Будет выполнено:

  • groupadd easypkg
  • usermod -aG easypkg $USER
  • /etc/sudoers.d/easypkg — NOPASSWD для менеджеров пакетов
sudo -S sh -c '...'
[sudo] password for user:
Готово. Пароль больше не потребуется.
